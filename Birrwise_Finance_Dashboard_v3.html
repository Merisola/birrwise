Privacy & security

The prototype does not connect to a live server or bank account.

Local browser dataChanges in this demo are held in memory and may reset when the page reloads.
API key protectionBackend authentication is planned, not active in this standalone HTML.
For production, use encrypted transport, server-side secrets, least-privilege access, secure backups and explicit consent for SMS access. Never store an API key in frontend JavaScript.
